# Phase 2 – Requirement Analysis

## Project Name
EduGenie – Google Gemini Powered Learning Assistant

## Functional Requirements
- User can enter an academic question.
- The system sends the question to Gemini AI.
- Gemini generates an answer.
- The answer is displayed to the user.
- User can ask another question.

## Non-Functional Requirements
- Simple and user-friendly interface.
- Fast response.
- Secure API key handling.
- Reliable error handling.

## Software Requirements
- Python 3.x
- FastAPI
- Uvicorn
- Jinja2
- Google Gemini API
- HTML, CSS, JavaScript

## Target Users
Students

## Basic Hardware Requirements
- Laptop, desktop, tablet or smartphone
- Internet connection
