# Phase 7 – Project Documentation

## Project Title

EduGenie: Google Gemini Powered Learning Assistant

## Introduction

EduGenie is a web-based AI learning assistant that uses Google Gemini to help students understand academic topics and get simple explanations.

## Problem Statement

Students may find it difficult to understand complex academic concepts and get immediate explanations when studying.

## Proposed Solution

EduGenie provides AI-generated educational responses through a simple web-based interface. Students can enter an academic question and receive a response generated using Google Gemini.

## Objectives

- Provide quick answers to academic questions.
- Explain difficult concepts in simple words.
- Provide an easy-to-use learning interface.
- Use Generative AI to support student learning.

## Main Features

- Academic question input
- AI-generated responses
- FastAPI backend
- Google Gemini integration
- Simple web interface
- Response display
- Empty question validation

## Working Process

1. Student enters an academic question.
2. EduGenie receives the question.
3. FastAPI processes the request.
4. The question is sent to Google Gemini.
5. Gemini generates an AI-based response.
6. EduGenie displays the response to the student.

## Technologies Used

- Python
- FastAPI
- Google Gemini API
- HTML
- CSS
- Jinja2
- Uvicorn

## Testing

The core functionality of the application was tested using different academic questions. Empty question detection and basic error handling were also tested successfully.

## Expected Result

The system accepts a student's academic question and generates an AI-based educational response through the EduGenie application.

## Future Enhancements

- AI-generated quizzes
- Study material summarization
- Personalized learning
- Multilingual support
- Document-based question answering
- Learning progress tracking
- Voice-based interaction

## Conclusion

EduGenie demonstrates how Generative AI can be integrated with a web application to support students in their learning process. The project combines FastAPI and Google Gemini to provide a simple AI-powered learning assistant.
