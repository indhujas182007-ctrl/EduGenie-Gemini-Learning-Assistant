# Phase 4 – Project Planning

## Project Name
EduGenie – Google Gemini Powered Learning Assistant

## Project Objective
To develop an AI-powered learning assistant that helps students understand academic topics using Google Gemini.

## Technology Stack
- Python
- FastAPI
- Google Gemini API
- HTML
- CSS
- JavaScript
- Jinja2
- Uvicorn

## Development Plan

1. Set up the development environment.
2. Create the FastAPI backend.
3. Connect Google Gemini API.
4. Develop the web interface.
5. Connect the frontend with the backend.
6. Test the application.
7. Fix errors and improve the application.
8. Prepare project documentation.
9. Record the final project demonstration.

## Team Responsibilities
The team will work together on backend development, frontend development, testing, documentation, and project demonstration.

## Expected Outcome
A working web-based AI learning assistant that accepts student questions and generates AI-based educational responses.
